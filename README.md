# Simulation de population de Daphnia magna

Travail de Maturité, Gymnase de Bienne et du Jura bernois (2026).

Simulation de la dynamique d'une population de daphnies par un modèle de Verhulst étendu, résolu avec la méthode d'Euler.

## Utilisation
Prérequis : Python 3, numpy, matplotlib

pip install numpy matplotlib
python simulation_daphnie.py

Le programme demande : population initiale, volume, nourriture, pH, heures de lumière et durée de la simulation.
